# 无障碍兼容与验收

本文记录 2026-09-26 新增的无障碍兼容实现。保留 Root 后端，用户手动选择模式，失败不自动换通道。版本文件未递增、未签名发布；源码接入不等于设备验证完成。

## 使用入口

1. 停止任务并等待动作收尾，在“设置 → 操作方式”选择“无障碍”。按钮点选后立即保存，不需要另点“保存设置”。老用户和未选择模式的用户仍默认 Root。
2. 点击“打开无障碍设置”，在系统中手动开启“阿尔泰手势辅助”。如果系统限制侧载应用启用无障碍，按系统提示在应用信息中允许相应设置。本应用不代为开启权限。
3. 返回后确认状态为“无障碍模式 · 已连接”，允许悬浮窗，切到目标游戏，从悬浮面板“选择当前游戏”。标记位置、配置周期、试走位和启动方式与 Root 相同。
4. 无障碍仅读取窗口包名与活动/焦点状态以确认前台，不保存控件文本。当前保守拒绝分屏、画中画、非默认显示屏、输入法可见、其他窗口取得焦点、锁屏和息屏。
5. 服务断开会停止任务；重新连接需要人工启动。回执取消/超时可能触发“未确认松手”，确认游戏触摸已复位后才能解除。切换模式不会清除这个安全闸门。

点击自家非聚焦悬浮面板时，允许它临时成为活动窗口，但下层仍必须是唯一聚焦的应用。不能确认窗口归属时不作此例外；其他活动/聚焦窗口继续阻止输入。

无障碍模式下，正常启动、轮询前台、执行技能/走位、查看系统安装日志均不调用 `su`。切换回 Root 后才使用原有 Root 查询、触摸与安装路径。

## 输入链路与关键约束

`Picks` / `WalkFlow` 共用 `TouchAction`，通过 `InputController` 选择后端。外层 `Actions` 动作互斥和 `InjectShield` 窗口让路保持共用。

- Root 后端沿用 `Probe → TouchProcess → TouchAgent → GestureSequence`，原命令参数由动作描述编码，现有回归校验协议及预算。
- 无障碍后端由 `AccessibilityInputService` 提交 `GestureDescription`；`AccessibleGestureRunner` 负责完整顺序和回调收尾，纯 Java 逻辑可离线测试。
- 推杆初始移动最多 30ms，其后以最多 150ms 的短段续接同一手指；每段收到完成回调才继续，最后一段设置不续接。点击 90ms 时是一段完整手势。
- 一轮走位仍是左 D、右 2D、左 D，两次 250ms 间隔；标了跳跃则再等 1000ms 后点击。无障碍模式的跳跃失败停止本轮，不吞掉可能表示服务断开的错误。
- 续接完成回调并不代表释放。停止/屏幕或前台改变时，等待当前段回执，在已知终点提交同一手指的释放段；不在其他位置追加点击。
- 单段回调预算为片段时长加 1500ms。已发送后缺失回执、被系统取消、释放段失败均作为未知触摸状态阻断后续输入。系统查询和 Binder 调用仍可能阻塞，不能把预算解释为严格停止延迟上限。
- 主线程排队超时的提交不会迟到执行；迟到回调不启动后续动作。每个动作绑定原服务实例，断开再连接不能使旧动作在新服务继续。

实际持续按压时间还包含片段回调与调度开销，不能保证与 Root 的事件时间轴完全相同。游戏是否接受持续推杆、同坐标续接与最终释放，必须在目标设备上确认。

## 未 Root 设备的更新

下载仍复用四个 HTTPS 来源、版本码和正式签名检查，不要求 Root。无障碍模式校验后保留 `filesDir/pending-update.apk`，记录目标版本和文件摘要；存在待安装文件时不覆盖，允许继续安装或主动丢弃。

用户点“安装已验证更新”后，如果尚未允许安装未知应用，会进入系统授权页；允许后返回再次点击安装。发送给系统安装器之前再次校验文件摘要、包名、签名和版本。`UpdateApkProvider` 非导出，只有固定 URI 的临时只读共享，不允许遍历目录、查询任意文件或写入。

“选择本地 APK 文件”使用 `ACTION_OPEN_DOCUMENT`，复制到应用缓存后走相同验证路径；复制限制 64 MiB，错误删除半包。无障碍模式的纯路径输入只读取应用自身有权限访问的文件，不使用 Root 绕过存储限制。

系统安装由用户确认，不保证自动重开。结果写入本地更新记录；启动/返回应用时核对实际版本，达到待更新版本后清理暂存文件。界面打开、安装器返回、实际版本是不同证据，不以“已打开安装界面”声称安装成功。安装后任务仍需人工启动。

## 本轮自动化验证

执行入口：

```bash
python3 tools/verify.py
source .toolchain/env.sh
.toolchain/gradle-8.2/bin/gradle :probe:automationRegression :probe:lintDebug :probe:assembleDebug --offline --no-daemon --console=plain
git diff --check
```

`AccessibilityRegression` 已加入 `AutomationRegression.main`，覆盖：

- 点击、整轮 1:2:1 走位及可选跳跃的方向、计划时长和间隔。
- 续接保持与最终释放；停止等待当前回执，然后只发送释放段。
- 中断标志恢复、服务拒绝、取消、缺回执、排队超时和迟到回调。
- 释放失败优先于取消；危险结果锁住全局输入；空闲切换不解除安全锁。
- 分屏、画中画、焦点变化、输入法、锁屏、非默认显示屏等前台门禁。
- 本地 APK 复制的完整性、空文件和大小边界、半包清理。

离线验证已通过 Java/Kotlin 编译、Android 资源与清单链接、原有及新增回归、DEX 转换。D8 仍报告仓库已有的 Java class file version 支持警告，不能据离线转换成功推断完整 Gradle 构建已通过。

完整 Gradle 检查在沙箱内因 `java.net.SocketException: Operation not permitted`（本地通信端口）失败，尚未进入任务验证；沙箱外执行请求被自动审批拒绝，原因是审批服务返回 503。未将 Lint 或 debug APK 构建记为通过。

| 前台切换、系统弹窗、旋转、锁屏 | 禁止新的不安全输入；部分走位失败不自动重放 |
