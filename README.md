# 阿尔泰（altair-buff）

阿尔泰是 Android 游戏辅助工具：可选择 Root 或无障碍输入，按用户标记的坐标定时点击最多四个技能，并可独立定时执行左、右、左走位与可选跳跃。界面由原生 Activity 和悬浮控制台组成。无障碍适配已接入源码，实际设备兼容性仍需验收。

当前项目只有 `:probe` 一个 Android 应用模块，包名为 `com.altair.probe`。不包含在线集控后端；自动识别、自由市场闭环等旧方案不属于当前应用功能。
